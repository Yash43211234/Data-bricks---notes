🔹 3. Main Concepts
🔸 Data Governance
Managing and controlling data
Ensuring security and access control

👉 Simple:
Store and control data in a proper way

🔸 Data Warehousing
A system to store large amounts of data
Used to get insights from data

👉 Simple:
Big storage for data analysis

🔸 ETL (Extract, Transform, Load)
Extract → Get data from source
Transform → Clean and process data
Load → Store into warehouse

👉 Simple:
Collect → Clean → Store

🔸 Data Sharing
Share data using links
Control who can access data

👉 Like Google Sheets sharing

🔸 Orchestration
Automate tasks (no manual work)
Schedule pipelines

👉 Example:
Run a job every day automatically

🔹 4. Databricks Architecture
Built on Lakehouse Architecture
Combines:
Data Lake + Data Warehouse

👉 Benefits:

Unified data platform
Better performance
🔹 5. Open Source Tools Used

Unity Catalog → Data governance
